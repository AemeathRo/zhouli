# 周丽没木

背景图 `bg.jpg` + 一行**由访客自己填**的文字。

- 线上地址：<https://aemeathro.github.io/zhouli/>
- 页面结构：`index.html`（HTML + CSS + 一小段脚本）+ `bg.jpg`（背景图）
- 背景显示方式：`center / contain`，**整张图完整显示、不裁切**，比例不合时四周留纯黑边。

## 文字和位置都是访客端的

页面上**不预设任何文字**。访客打开后，中间显示两行提示：「点这里输入文字 / 按住可以拖到任意位置」。

**写文字**

- 点一下就能打字，按 <kbd>回车</kbd> 或点空白处结束；
- 内容存在**访客自己浏览器的** `localStorage`（键名 `zhouli-text`）里，刷新、重开都还在；
- 每个访客一份，**互不影响**，你这边不需要做任何事；
- 访客把文字删光，提示会重新出现。

**挪位置**

- 在文字上**按住拖动**即可挪到任意位置（鼠标和触屏都行），鼠标移上去是「抓手」光标；
- 点一下不拖动 = 进入编辑，移动超过 5px 才算拖动，两者不打架；
- 位置同样记在访客自己的浏览器（键名 `zhouli-pos`），刷新后还在；
- 位置会被限制在画面内（四周留 8px），拖不出视野；窗口尺寸变化、文字变长换行后会自动重新校正，不会跑到看不见的地方。

标签页标题会跟着访客输入的文字变（没输入时用 `index.html` 里 `<title>` 的值）。

## 换背景图

直接替换根目录的 `bg.jpg` 即可，代码不用改（若换文件名，同步改 `<body>` 里 `background` 的 `url()`）。

## 本地预览

```bash
start index.html             # 直接双击打开
python -m http.server 8000   # 或起个本地服务，然后访问 http://localhost:8000
```

## 部署

仓库根目录 + `main` 分支已开启 GitHub Pages，推送到 `main` 即自动发布。访客各自编辑的内容存在各自浏览器，不需要后台，静态托管即可。
